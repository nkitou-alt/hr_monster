## 最初の依頼

4体に渡した依頼は、次のとおりです。ここから研修が1本できあがるまでを、ステップごとに公開します。

> ソラノワ株式会社（架空のBtoB SaaS企業、社員300名）で、入社2〜5年目の若手24名を対象に「問題解決力研修（ロジカルシンキング編）」をつくりたい。形式は事前学習と当日1日の反転学習。若手の提案や改善が「解決策ありき」になりがちで、手戻りが多いことが企画の背景。

<p class="note">ソラノワ株式会社は架空の会社です。登場する数字や事実もすべて作例用の設定です。</p>

{% include step.html n=1 monster="toimon" skill="training-concept" title="研修コンセプトシート" %}

トイモンは「そもそも、なぜこの研修をやるのか」から考えます。最初に引っかかったのは、ロジカルシンキングと、共通コンテキストの最上位原則「対話からの創発」との相性です。ロジカルシンキングは、ともすると「正解を一人で導く技術」として教えられます。そこでこの研修では、ロジックを**正解を出す道具ではなく、他者と問いを磨くための共通言語**として位置づけました。

### 研修の一文

仕事に着手する前に「それは、本当に解くべき問題か」を問い直し、他者との対話で問題を磨けるようになる研修。

### セオリー・オブ・チェンジ

| 段階 | 中身 |
|---|---|
| 条件づくり | 型（4つの問い・ロジックツリー・結論から伝える）を事前にそろえ、当日は「型どおりに解いたのに外れる」安全な失敗を体験する |
| 内的状態の変化 | 解く前に問いを疑う構えが生まれる。思い込みに気づく怖さと面白さを知る |
| 行動 | 仕事に着手する前に、上司や関係者と「何が問題か」を3分で擦り合わせる |
| 成果 | 手戻りが減り、提案が一度で通る。的外れな施策に時間を使わない |

### 失敗形態と防波堤

| この研修がズレるとしたら | 防波堤 |
|---|---|
| 型の暗記がゴールになる（「MECEに分けられた＝できた」） | ワークの評価観点を「型の正しさ」ではなく「問いが変わったか」に置く。振り返りでも毎回「問いがどう変わったか」を聞く |
| ロジックが、相手を言い負かす道具になる | 対話ワークのルールを「相手の穴を指摘するのではなく、問いで返す」にする。足場の問いカードはすべて疑問形にする |

### 射程

- **効く場面**：原因が複数ありそうで、関係者の合意が必要な問題
- **効かない場面**：緊急対応（まず止血が先）、手順が決まっている定型業務、価値観の対立が本質の問題（対話と合意形成が先）

射程は研修の冒頭で受講者にも伝えます。「何にでも効く」と言わないことが、内容への信頼をつくります。

### 最重視の到達点と学習目標

**最重視の到達点**：着手する前に、それが本当に解くべき問題かを問い、定義し直せる。

| 学習目標 | 受講後にできること |
|---|---|
| ① 問題を定義し直す | 着手する前に「それは、本当に解くべき問題か」を問い、問題を一文で定義し直せる |
| ② 分解して絞り込む | ロジックツリーで問題を分解し、手を打つ場所を絞り込める |
| ③ 結論から伝え、問いで磨く | 結論から3分で伝え、相手の問いで自分の考えを磨ける |

この3つの言葉（**定義し直す／分解して絞り込む／問いで磨く**）を、振り返り・アンケート・1か月後のフォローまで一本で通します。

### 中心命題とメインワーク

**中心命題**：問題解決の質は、解き方より、問いの立て方で決まる。

**メインワーク「解いたのに、外れた」**：チームでケースの問題をロジックツリーで分解し、打ち手を発表します。発表のあと、伏せてあった封筒を開けると、追加の事実が出てきます。その事実を見ると、自分たちが解いていた問題そのものがずれていたことが分かります。受講者は「問いの立て方で結果が変わる」を、話として聞くのではなく、自分の失敗として体験します（命題の発火）。

**起爆装置**：ケースは「対応時間を短くする打ち手を考えてください」という**How（どうするか）の問い**で渡します。受講者は自然に解決策から考え始めます。この入り口が、あとで裏切られる思い込みをつくります。

### キービジュアルと配色

**4つの問いの階段**：What（何が問題か）→ Where（どこで起きているか）→ Why（なぜ起きるか）→ How（どうするか）。事前学習では左から右への一方向の矢印だけを見せ、当日のセッション2で「How から What へ戻る矢印」を書き足します。同じ図を、テキスト・スライド・ワークシート・持ち帰りカードのすべてで使います。

- メインカラー（緑）：問いを深める側。4つの問い、戻る矢印
- アクセントカラー（オレンジ）：飛びつきと思い込みの側。How から始まるケースの問い

### 正文

研修全体を貫く問いを、次の一文に定めます。

> **それは、本当に解くべき問題ですか？**

オープニングのスライド → 封筒を開けたあとの講師の一言 → 問いカードの1枚目 → 持ち帰りカード、と同じ文言のまま4回登場させます。

### さらに良くする観点（トイモンからの提案）

1. ケースの業界を、受講者の会社の事業に近づける。自社の話だと、封筒の衝撃が増す
2. 宿題の困りごとが大きすぎる人向けに、範囲を絞るための足場を用意する
3. 1か月後のフォローで、受講者の上司にも1問だけ聞く。行動の変化を外からも確かめられる

### メインワークのケース

**ケース資料（セッション2冒頭で配布）**

> ソラノワ株式会社のカスタマーサポート部では、問い合わせ1件あたりの平均対応時間が、この半年で約1.5倍に伸びています。部長からは「対応時間を短くする打ち手を考えてほしい」と頼まれました。チームで原因を分解し、打ち手を提案してください。

**封筒の中身（発表のあとに開封）**

1. 対応時間が伸びているのは、半年前に始まった新料金プランの契約者からの問い合わせだけである
2. その問い合わせの約7割は「請求書の見方が分からない」という内容である
3. 請求書のレイアウトは、新料金プランの開始と同時に変更されていた
4. サポート担当者の対応品質の評価は、前年と同じ水準である

多くのチームは「担当者のスキル」「FAQの不足」「ツール」などに分解し、研修やFAQの拡充を打ち手にします。封筒を開けると、解くべき問題は「対応時間」ではなく「請求書が分かりにくく、問い合わせを生んでいること」だと分かります。問題の場所は、サポート部の外にありました。

### ワークシート

**セッション2「問題を定義し直す」（チームで1枚）**

1. 最初に渡された問いは、何でしたか。（1行）
2. 封筒の事実を見て、最初の問いのどこがずれていたと思いますか。（3行）
3. いま、解くべき問題を一文で書くと、何ですか。（2行）
4. その問題は、最初の困りごと（対応時間）と、どうつながっていますか。（3行）

**セッション3「ペアインタビュー」問いカード（聴き手用・6枚）**

1. それは、本当に解くべき問題ですか？
2. いつから、どこで起きていますか？
3. 起きていないのは、どこですか？
4. 困っているのは、誰ですか？
5. その事実は、誰が、どうやって確かめましたか？
6. それが解決したら、何が変わりますか？

聴き手のルール：解決策やアドバイスは言わず、問いだけで返す。カードは足場なので、自分の言葉の問いを使ってもよい。

**セッション3「話し手シート」**

1. 宿題で書いてきた困りごとは、何でしたか。（2行）
2. 相手の問いで、気づいたことは何ですか。（4行）
3. 困りごとを、解くべき問題として一文で定義し直すと、何ですか。（2行）

**セッション4「AIの問いを吟味する」で使うプロンプト**

```
次の「問題の定義」について、前提を疑う問いを5つ挙げてください。
答えやアドバイスは書かず、問いだけを挙げてください。

問題の定義：（自分で書いた一文）
```

AIの問いは答えではなく、吟味の叩き台です。5つのうち「自分では思いつかなかった問い」を1つ選び、自分で答えます。

### 講師ガイド（抜粋）：封筒を開ける場面

> **講師**：皆さん、発表ありがとうございました。どのチームも、事前学習の型をきちんと使って原因を分解できていましたね。
> （型を正しく使えていたことを、先に認める。この後の種明かしで、受講者が責められていると感じないように）
>
> **講師**：では、机の真ん中の封筒を開けてください。サポート部が集めた追加の事実が4つ入っています。2分で、チームで読んでみてください。
> （2分待つ。ざわつき始めても、説明を足さない）
>
> **講師**：どうでしょう。皆さんの打ち手は、この事実を見ても有効でしょうか。

**想定される反応**：「最初から教えてほしかった」「ずるい」
**返し方**：「そうですね。実は、仕事で渡される問題も、たいていこの形で届きます。最初に渡された問いが、正しいとは限らないんです」と受け止めてから、スライドの正文を示します。

> **それは、本当に解くべき問題ですか？**

**つまずいたときの足場**：再定義が進まないチームには「対応時間が伸びていないのは、どこですか？」と問いカード3番の問いを投げます。

### 直後アンケート

1. 学習目標①〜③それぞれについて、自信の度合い（4段階：とてもある／ある／あまりない／ない）
2. 今日いちばん印象に残った場面と、その理由（自由記述）
3. 持ち帰り宣言：来週、誰に、どの問題を、3分で話しますか（自由記述）
4. 自分の職場で、この研修の考え方が使えそうな場面と、使いにくそうな場面（自由記述）
5. 運営面で改善してほしいこと（自由記述）

**匿名か記名か**：記名にします。1か月後のフォローと結びつけ、持ち帰り宣言が実行されたかを確かめるためです。率直さを補うため、運営面の設問だけは任意回答にします。

満足度の設問は、あえて入れていません。満足度は高くても、行動が変わらない研修はあるからです。

### 1か月後のフォロー

- 学習目標①〜③の「1か月後のフォロー」の設問（上の表）
- 持ち帰り宣言は実行できましたか。できなかった場合、何が妨げになりましたか
- 研修のあと、問題を定義し直したことで、手戻りが減った・提案が通ったなどの変化はありましたか（具体的に）

セオリー・オブ・チェンジの「行動」と「成果」の段に対応しています。

### 回答が集まったら

1. 4段階の回答は、平均だけでなく分布を見る。「あまりない・ない」と答えた人の自由記述を必ず読む
2. 自由記述はAIで構造化して傾向をつかむ。ただし出力は吟味の対象として扱い、元の回答に戻って確かめる
3. セオリー・オブ・チェンジのどの段で止まっているかを特定する（例：自信はついたが、1か月後に行動が起きていない → 職場での話し相手づくりが足りない）
4. 受講者が実際に問題を定義し直した事例を「実践知」として集め、次回のミニケースやテキストに還流する

## この作例の使い方

この研修は、そのまま自社で実施できます。ケースの業界を自社の事業に近づけ、宿題の例を自社の仕事に差し替えると、より効果が上がります。

4つのスキルを使えば、別のテーマの研修も同じ流れでつくれます。最初の依頼を自社の研修に書きかえて、トイモンから順に渡してみてください。
