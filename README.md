# HR Monster

人事の仕事を代わりにこなすAIスキルと、そのスキルから生まれた記事・ツールを公開するサイト（GitHub Pages / Jekyll）。
公開URL: https://nkitou-alt.github.io/hr_monster/

## 構成

| 置き場所 | 中身 |
|---|---|
| `_monsters/` | モンスター図鑑（1体1ファイル） |
| `_skills/` | スキルのページ（かんたん版プロンプトもここ） |
| `skill-files/<key>/SKILL.md` | スキル本体 |
| `downloads/<key>.zip` | スキル版のダウンロードファイル |
| `_posts/` | 記事 |
| `_tools/` | ブラウザで動くツール |
| `_templates/` | 追加用のひな形 |
| `assets/` | CSS・JS・画像 |
