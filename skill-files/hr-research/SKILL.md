# HRリサーチ（シラベル）

人事担当者の「これ、世の中ではどうなってる？」に、出典付きで答えるためのスキル。
目的は情報を集めることではなく、**読んだ人事担当者が次の一手を決められる状態をつくること**。

## 1. 問いを確かめる

調べ始める前に、次の3点がはっきりしているか確認する。依頼文から読み取れない点だけを、1〜2問で質問する。

- **テーマ**：何について知りたいか（例：1on1の効果、スキルベース採用の導入事例）
- **用途**：調べた結果を何に使うか（社内提案、制度設計、研修の材料、情報収集）
- **範囲**：期間（指定がなければ直近3年）、地域（指定がなければ米国・欧州・日本）

用途が分かれば、深さと書き方が決まる。社内提案なら「導入した企業と成果」、制度設計なら「設計の選択肢と論点」を厚くする。

## 2. 調べる

情報源は、信頼性の高い順に当たる。

1. **一次情報**：学術論文、公的統計（厚生労働省、OECD、米国労働統計局など）、企業の公式発表
2. **専門機関**：SHRM、CIPD、Gartner、McKinsey、Deloitte などの調査レポート
3. **専門メディア**：HR Dive、HR Executive、日本の人事専門誌など

守ること：

- 数字や主張には、必ず出典を1つ以上ひもづける。出典のない数字は書かない。
- 調査会社のレポートは、サンプル数と対象（国・業種・企業規模）を確認して添える。
- 見つからなかったことは「見つからなかった」と書く。推測で埋めない。
- 主張が割れているテーマは、両方の立場を紹介する。

## 3. まとめる

次の構成でレポートを書く。

```
# （テーマ）リサーチレポート

## 結論（3行）
調べて分かったことを3行で。読み手がここだけ読んでも判断できるように書く。

## 背景：なぜいま、このテーマか

## 分かったこと
- 論点ごとに見出しを立て、事実→出典の順で書く

## 事例
- 企業名／取り組み／成果（数字があれば）／出典

## 日本企業への示唆
- 海外の事例をそのまま持ち込めない点（雇用慣行、法制度、文化）にも触れる

## 次の一手（提案）
- 用途に合わせて、具体的なアクションを2〜3個

## 出典一覧
- [タイトル](URL)　発行元・発行年
```

## 4. 書き方のルール

- 日本語で、言い切りの文体で書く。「〜と考えられます」を重ねない。
- 専門用語は、初出で一言説明を添える。
- 1つの段落に1つの主張。
- 結論と「次の一手」は、用途に合わせて具体的に書く。一般論で終わらせない。

## 5. 仕上げのチェック

出す前に、次を確認する。

- [ ] すべての数字に出典がついている
- [ ] 出典のリンクが実在し、内容と一致している
- [ ] 結論3行だけで、要点が伝わる
- [ ] 日本企業への示唆が、海外の話の言い換えになっていない
