# 研修運営（モテナン）

受講者が安心して学べるように、研修の「前」と「当日」を整えるスキル。
どれだけ良いプログラムも、案内が分かりにくい、会場が寒い、資料が足りないといった小さなつまずきで台無しになる。モテナンはそれを先回りして防ぐ。

## 最初に読むもの

1. `references/training-context.md`：特に第2章（受講者の前提）、第3章（グループ編成の原則・情報開示マップ）
2. `references/design-process.md`：特に「ファイル運用ルール」（プレースホルダ規約・正文の同期）
3. 入力：時間割・事前学習の構成・宿題の正文（「研修プログラム開発」スキルの出力）。無ければ日程・対象者・人数・形式を最初に確認する。

## 進め方

### 1. 受講者の一日を想像する

案内を受け取ってから、研修が終わって職場に戻るまでを、受講者の目線で時系列に書き出す。各場面で「受講者が不安になること・迷うこと」を洗い出し、手当てを決める。
受講者は業務で忙しく、研修に割ける時間と集中力は限られている。案内は一読で分かる短さにし、「なぜ今これを学ぶのか」を最初に伝える。

### 2. 案内文をつくる

- 案内は段階に分ける：開催案内（日程確保）→ 事前学習の案内 → 前日リマインド → 研修後のお礼と持ち帰りの依頼。
- 宿題や依頼の文言は**正文からコピーし、改変しない**。媒体ごとに言い回しが割れると、持ち込まれる素材が割れる。
- 情報開示マップを守る。当日の山場に関わる内容を案内で明かさない。
- 未確定事項（日付・会場・URLなど）は【 】で書き、末尾に未確定リストをつける。

### 3. グループを編成する

部門横断の交流に価値がある研修では、編成を運任せにしない。

- 同じ部門の人、評価関係（上司と部下）にある人を同じグループにしない
- 業務の接点が薄い組み合わせを優先する
- 当日のシャッフルはしない（交流の広さは編成で担保し、当日は固定で深さをつくる）
- 小グループに分けるときも、利害関係のあるペアを避ける
- 昼食も同じグループにすると、非公式の交換の時間になる

### 4. 準備と当日の運営を決める

- 準備チェックリスト：3週間前／1週間前／前日／当日朝 に分ける。
- 当日の運営表：時刻、講師の動き、事務局の動き、配布物、機材。
- 種明かしのあるワークでは、種明かしの前に配る紙と後に配る紙を物理的に分け、配布のタイミングを運営表に書く。
- 進行が押したときの削り順を、講師と事務局で共有しておく。

### 5. 受講体験を磨く

チェックイン・休憩・昼食・クロージングといった「つなぎ」の時間を、受講者が安心できる場として設計する。会場の温度、BGM、名札、飲み物、休憩明けの合図など、小さな気配りを具体的に挙げる。

## 出力（必要なものを、この順で）

1. **受講者の一日**：時系列の場面と、不安・迷いへの手当て
2. **案内文一式**：開催案内、事前学習の案内、前日リマインド、研修後のメール
3. **グループ編成のルール**と、名簿を入れれば編成できる手順
4. **準備チェックリスト**（時期別）
5. **当日の運営表**（講師・事務局・配布物・機材）
6. **未確定リスト**（【 】の一覧）

## 品質チェック

- [ ] 宿題・依頼の文言が、すべての媒体で正文と一字一句同じ
- [ ] 案内に当日の山場のネタバレがない
- [ ] 編成ルールで評価関係・同部門が同じグループにならない
- [ ] 種明かし前後の配布物が分かれている
- [ ] 受講者が迷いそうな場面に、すべて手当てがある
